## 📂 Selected Projects

### 📊 Delivery Process Bottleneck Analysis  
**End-to-end Power BI analysis of e-commerce delivery bottlenecks using the Olist dataset.**

Repository:  
👉 https://github.com/ipiotrowski/Delivery-Process-Bottleneck-Analysis

Scope:
- end-to-end analytical design built entirely in Power BI, covering ETL, data modeling, business logic, and reporting
- decomposition of the order lifecycle into fulfillment stages to identify where delivery delays are introduced
- star-schema-based data model with bridge tables, optimized for analytical flexibility and drill-through
- business logic implemented in DAX as a semantic layer, including composite metrics to assess bottleneck severity and risk
- interactive report structure combining executive-level overview with diagnostic drill-through analysis
